EDZÉSNAPLÓ – telefonos edzésnapló

Mit tud:
- 3 edzés, a képeken szereplő 18 gyakorlattal
- Ajánlás: 2–3 sorozat × 5–9 ismétlés
- Súly (kg) és ismétlésszám rögzítése
- Sorozatok kipipálása
- Az előző edzés eredményeinek automatikus megjelenítése
- Adatok mentése a telefon böngészőjében
- Előzmények
- JSON export/import biztonsági mentés

iPhone-on:
1. A mappát tedd fel egy HTTPS-es tárhelyre (pl. GitHub Pages / Netlify).
2. Safari-ban nyisd meg az index.html oldalát.
3. Megosztás → Főképernyőhöz adás.
4. Ezután alkalmazásként indítható.

A mentések alapból az adott készülék böngészőjében maradnak.
